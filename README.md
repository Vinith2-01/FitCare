# 🌿 FitCare — Friendly Health & Fitness Hub

Welcome to **FitCare**, a comprehensive, friendly, evidence-based health, nutrition, and fitness web application designed to empower your wellness journey without guilt, extreme diets, or intimidating gym jargon.

---

## 🚀 How to Launch

No installations, build steps, or command line servers are required!

1. Open this project folder: `E:\project health`
2. Double-click **`index.html`** (or right-click and choose *Open with Google Chrome*, *Microsoft Edge*, *Brave*, or *Firefox*).
3. That's it! Your complete friendly health hub is live and ready.

*(Optional Developer Server)*: Run `python auth-server.py` if you want to test the Python backend endpoint for syncing user registrations to `users.json`.

## 💻 Tech Stack
- **Frontend**: Vanilla HTML5, Modern CSS3 (CSS Variables, Flexbox, Grid, Glassmorphism, Dark/Light Themes), Vanilla JavaScript (ES6+).
- **Visualization**: Chart.js for reactive macro distributions, custom SVG for Vitality Score ring.
- **Audio Engine**: Web Audio API for custom sound synthesis and ambient nature soundscapes.
- **AI Engine**: Pattern-matching NLP rule engine with dynamic state integration and Web Speech API.
- **Storage**: Client `localStorage` + optional Python backend server writing to `users.json`.
